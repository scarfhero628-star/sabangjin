# 사방진 정령결투

물·불·나무·흙 정령을 지휘해 마나샘을 차지하고, 상대 소환사 흑월을 쓰러뜨리는 **턴제 전략 게임**입니다.  
HTML 파일 하나로 돌아가며, 휴대폰 홈 화면에 **앱처럼 설치**할 수 있습니다.

▶ **플레이:** https://scarfhero628-star.github.io/sabangjin/

## 휴대폰 홈 화면에 설치하기

**안드로이드 (크롬)**
1. 위 주소를 크롬으로 엽니다.
2. 오른쪽 위 ⋮ 메뉴 → **「홈 화면에 추가」** 또는 **「앱 설치」** → 설치
3. 홈 화면의 사방진 아이콘으로 실행 (주소창 없이 전체 화면)

**아이폰 (사파리)**
1. 위 주소를 사파리로 엽니다.
2. 아래쪽 공유 버튼 → **「홈 화면에 추가」** → 추가
3. 홈 화면 아이콘으로 실행 (첫 터치에 주제곡이 나옵니다)

한 번 실행하면 휴대폰에 저장되어 **인터넷이 없어도** 플레이할 수 있습니다.

## 대전 방식

| 방식 | 이 주소에서 |
|---|---|
| 컴퓨터와 겨루기 | ✅ |
| 2인 대전 (한 기기에서 번갈아) | ✅ |
| 온라인 대전 (각자 다른 기기) | claude.ai에 게시된 페이지에서만 가능 |
